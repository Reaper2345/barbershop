# Проект в OSPanel

Файл конфигурации проекта: `.osp/project.ini`. Секция `[barbershop]` задаёт домен,
`web_root` указывает на `public` — именно этот каталог должен отдавать Apache.

## Если проект не появился в списке

1. Модуль **PHP** включён: OSPanel → **Modules** → должен быть активен `PHP-8.2`
   (или другой установленный модуль).
2. В `.osp/project.ini` значение `php_engine` **точно совпадает** с именем папки модуля
   в `C:\OSPanel\modules` — например `PHP-8.2`, `PHP-8.5`. Имя чувствительно к регистру.
3. OSPanel **перезапущен** после правки `project.ini`: настройки читаются при старте.
4. В файле `C:\Windows\System32\drivers\etc\hosts` есть строки:
   `127.0.0.1 barbershop` и `127.0.0.1 barbershop.local`.
   Обычно OSPanel добавляет их сам, но при отключённом модуле **Bind** это нужно сделать вручную.
5. Антивирус (или Defender с защитой папок) не блокирует запись в `hosts` —
   иначе домен не резолвится, хотя проект запущен.

## Открыть сайт

<http://barbershop> или <http://barbershop.local>

Проверка HTTP: OSPanel → **Domains** → домен `barbershop` должен быть в статусе **on**.
